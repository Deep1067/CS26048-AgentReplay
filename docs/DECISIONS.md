Model-call replay is implemented and validated for explicit model wrappers (the ADK-style loop). For LangGraph, model calls are recorded for audit/cost tracking but the live model is still called during replay; LangGraph model-call substitution is a known limitation, listed in Future Work.

Live Run endpoint (POST /api/live/run) is disabled by default and can be enabled only with the server-side LIVE_RUN_ENABLED setting in a trusted environment. Runs are capped at 5 steps via StepCappedStorage and internally time-boxed at 15 s using asyncio.wait_for so a partial session is saved and returned on timeout, preventing a raw Vercel 504. Configuration mutations are separately disabled by default through CONFIG_MUTATIONS_ENABLED.

For session-loading performance, use grouped database aggregates for the session list and overview, and defer trace/history requests until their views are opened. Keep the public session-summary response and cost semantics unchanged; do not add cross-user caching. Defer the external font stylesheet so it does not block initial rendering. These choices were validated with synthetic local SQLite and browser measurements only; Vercel and Turso performance remain unverified until the authorized private-staging gate is met.
